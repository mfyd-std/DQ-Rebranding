# DQ Rebranding — Website Pondok Pesantren Daar el-Qolam

Proyek rebranding website resmi Pondok Pesantren Daar el-Qolam. Dibangun sebagai static website menggunakan HTML, CSS, dan JavaScript murni tanpa framework.

## Live Preview

🔗 https://dq-rebranding.netlify.app

## Halaman

| Halaman | Deskripsi |
|---|---|
| `index.html` | Beranda — Hero, Video, Program, Berita, FAQ |
| `program.html` | Program Pendidikan — Reguler, Excellent, Dirasah |
| `dq3.html` | DQ3 Kampus Dza'Izza |
| `tentang.html` | Profil, Visi Misi, Pimpinan, Sejarah |
| `jelajahi.html` | Fasilitas, Kehidupan Islami, Ekskul, Asrama |
| `berita.html` | Berita & Kegiatan |
| `kontak.html` | Kontak, Lokasi, Form WhatsApp |

## Teknologi

- HTML5, CSS3, Vanilla JavaScript
- Tailwind CSS (via CDN)
- Google Fonts: Cormorant Garamond, Plus Jakarta Sans, Amiri
- Deploy: Netlify (auto-deploy dari GitHub)
